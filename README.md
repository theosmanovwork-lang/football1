# Футбольный менеджер как рабочее приложение

Стартовый набор проекта для разработки в Claude Code.

## С чего начать

1. **SETUP.md** — что установить и как (Git, Node.js, Claude Code, плагины, MCP).
2. **PROMPTS.md** — готовые запросы для Claude Code, начиная с первого.

## Что внутри

| Файл | Для кого | Что это |
| --- | --- | --- |
| `CLAUDE.md` | Claude Code | Правила проекта: стек, архитектура, как работать. Claude читает его при каждом запуске |
| `docs/concept.md` | Все | Концепция игры |
| `docs/stack.md` | Все | Стек и архитектура |
| `docs/decisions.md` | Все | Журнал принятых решений |
| `docs/tasks/T001-prototype.md` | Claude Code | Первая задача: недельный прототип и проверка стека |
| `docs/reports/` | Все | Отчёты по задачам |
| `.claude/settings.json` | Claude Code | Разрешения: какие команды Claude может запускать без вопросов |
| `SETUP.md`, `PROMPTS.md` | Вы | Установка и готовые запросы |
