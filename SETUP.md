# Установка: всё, что нужно, чтобы начать работать в Claude Code

Инструкция для Windows и macOS. Выполняйте по порядку. Займёт 30–60 минут.

## Что есть что

- **Claude Code** — ИИ-разработчик, который работает в терминале в папке проекта: пишет код, запускает команды, тестирует.
- **Плагин** — пакет расширений для Claude Code, ставится одной командой. Может содержать навыки (skills), команды и подключения к сервисам.
- **Навык (skill)** — набор инструкций, который Claude Code подключает сам, когда задача подходит (например, «как делать красивый интерфейс»).
- **MCP-сервер** — мост между Claude Code и внешней программой или сервисом (браузер, Figma). Через него Claude «видит» и управляет этой программой.

## Шаг 1. Подписка

Claude Code работает с подпиской Claude Pro или Max. Бесплатный план Claude.ai доступа к Claude Code не даёт. Для долгой разработки удобнее Max: больше лимитов.

## Шаг 2. Git

**Windows:** скачайте и установите Git for Windows с git-scm.com (все настройки по умолчанию). Он нужен ещё и потому, что Claude Code на Windows использует его оболочку Git Bash.

**macOS:** откройте Терминал и выполните:

```
xcode-select --install
```

Проверка в терминале: `git --version` выводит номер версии.

## Шаг 3. Node.js

Установите версию **LTS** с сайта nodejs.org.

- Windows (альтернатива): `winget install OpenJS.NodeJS.LTS` в PowerShell.
- macOS (если есть Homebrew): `brew install node`.

Проверка: `node --version` и `npm --version` выводят номера версий. Перезапустите терминал после установки.

## Шаг 4. Claude Code

**macOS** (Терминал):

```
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows** (PowerShell, не CMD):

```
irm https://claude.ai/install.ps1 | iex
```

Альтернатива на macOS: `brew install --cask claude-code`.

Claude Code требует **macOS 13 (Ventura) или новее**. На macOS 12 он не запустится — тогда обновите систему или работайте через браузер на claude.ai/code (облачная сессия с этим репозиторием).

Проверка: `claude --version`. При первом запуске команда `claude` попросит войти в аккаунт Claude.

Актуальная инструкция: https://code.claude.com/docs/en/setup

## Шаг 5. Папка проекта и GitHub

1. Создайте папку, например `Documents/fm-project`.
2. Распакуйте в неё этот стартовый набор (так, чтобы `CLAUDE.md` лежал прямо в папке).
3. Откройте терминал в этой папке и выполните:

```
git init
git add .
git commit -m "chore: starter kit"
```

4. Создайте на github.com **приватный** репозиторий и подключите его (GitHub покажет команды `git remote add` и `git push` после создания). Или попросите Claude Code сделать это за вас.

## Шаг 6. Плагины в Claude Code

Запустите в папке проекта `claude` и введите по очереди:

```
/plugin install frontend-design@claude-plugins-official
/plugin install context7@claude-plugins-official
/plugin install code-review@claude-plugins-official
```

Официальный каталог плагинов Anthropic подключён в Claude Code заранее. Посмотреть всё доступное: `/plugin` → вкладка Discover. После установки перезапустите Claude Code.

Что дают:

- **frontend-design** — Claude делает выразительный интерфейс вместо типового «ИИ-вида». Включается сам при работе над интерфейсом.
- **context7** — Claude подтягивает актуальную документацию библиотек (React, Electron, TanStack) и не пишет код по устаревшим версиям.
- **code-review** — проверка изменений перед коммитом.

## Шаг 7. Playwright MCP (глаза Claude Code)

Позволяет Claude открыть интерфейс в браузере, нажимать кнопки и делать скриншоты. Выполните в терминале (не внутри Claude Code):

**macOS:**

```
claude mcp add --scope user playwright -- npx -y @playwright/mcp@latest
```

**Windows:**

```
claude mcp add --scope user playwright -- cmd /c npx -y @playwright/mcp@latest
```

Проверка: запустите `claude`, введите `/mcp` — в списке должен быть `playwright`. При первом использовании он сам скачает браузер. В первый раз в запросе можно явно написать «используй playwright mcp».

## Шаг 8. Figma (когда начнёте делать макеты)

1. Зарегистрируйтесь на figma.com — бесплатного тарифа достаточно.
2. В Claude Code:

```
/plugin install figma@claude-plugins-official
```

3. Перезапустите Claude Code, введите `/mcp`, выберите `figma` и пройдите вход в аккаунт Figma.
4. Как пользоваться: в Figma выделите фрейм экрана → правый клик → Copy link to selection → вставьте ссылку в Claude Code с просьбой сделать экран по макету.

Альтернатива без плагина: `claude mcp add --scope user --transport http figma https://mcp.figma.com/mcp`.

## Шаг 9. Steam (на неделе прототипа)

Установите обычный клиент Steam с store.steampowered.com и войдите в аккаунт. Он понадобится для проверки интеграции в задаче T001. Аккаунт разработчика Steamworks и оплата Steam Direct ($100 за игру) понадобятся только перед публикацией.

## Шаг 10. Первый запуск

Откройте `PROMPTS.md` и скопируйте первый запрос в Claude Code.

## Если что-то не работает

- `claude` не найден — перезапустите терминал; на Windows иногда нужно выйти из системы и войти снова.
- На Windows ошибка про `&&` — вы запустили команду для CMD в PowerShell или наоборот. Команды выше рассчитаны на PowerShell.
- Playwright или Figma не видны в `/mcp` — перезапустите Claude Code; проверьте, что Node.js установлен.
- Любая другая ошибка — скопируйте её текст в Claude Code и попросите разобраться.
