# Готовые запросы для Claude Code

Копируйте запросы как есть. Запускайте `claude` из папки проекта.

## Полезные приёмы

- **Режим планирования:** нажмите Shift+Tab, пока внизу не появится режим плана. Claude сначала составит план и ничего не изменит без вашего одобрения. Используйте для каждого нового шага.
- **Остановить Claude:** клавиша Esc.
- **Новая тема:** `/clear` очищает контекст. Делайте это между задачами — Claude заново прочитает `CLAUDE.md`.
- **Проверить подключения:** `/mcp`.
- **Не понимаете, что произошло:** спросите «объясни простыми словами, что ты сейчас сделал и как мне это проверить».

---

## 1. Знакомство с проектом (первый запуск)

```
Прочитай CLAUDE.md, docs/concept.md, docs/stack.md, docs/decisions.md и docs/tasks/T001-prototype.md.
Перескажи своими словами, что мы делаем и какой первый шаг, и задай вопросы, если что-то неясно.
Проверь, что у меня установлены Node.js и Git. Код пока не пиши.
```

## 2. Выполнение шага задачи

Включите режим планирования (Shift+Tab), затем:

```
Выполни шаг 1 из docs/tasks/T001-prototype.md.
Сначала покажи план. После выполнения запусти все проверки, сделай коммит
и объясни мне простыми словами, как самому убедиться, что всё работает.
```

Для следующих шагов меняйте номер шага.

## 3. Проверка интерфейса глазами Claude

```
Запусти npm run dev:web, открой интерфейс через playwright mcp
и сделай скриншоты всех разделов в светлой и тёмной теме.
Опиши, что видишь, и исправь всё, что выглядит неаккуратно или сломано.
```

## 4. Экран по макету из Figma

```
Вот ссылка на фрейм в Figma: <вставьте ссылку>.
Сделай этот экран в нашем приложении, используя наши компоненты, темы и CSS-переменные.
Сверь результат с макетом через скриншот playwright mcp.
```

## 5. Ревью перед коммитом

```
Проверь все изменения с последнего коммита: соблюдены ли правила из CLAUDE.md,
нет ли игровой логики в React-компонентах, есть ли тесты на новую логику ядра.
```

## 6. Отчёт по задаче

```
Задача T001 выполнена. Заполни docs/reports/T001.md: что сделано, все замеры с описанием компьютера,
проблемы, инструкция для меня по ручной проверке Steam и твоя рекомендация по стеку.
Обнови docs/decisions.md.
```

## 7. Следующая задача

```
Предложи формулировку задачи T002 по порядку сборки MVP из docs/concept.md (раздел 10).
Оформи её в docs/tasks/T002-<название>.md в том же формате, что T001. Код не пиши.
```
