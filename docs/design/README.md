# Макеты экранов

Эталонные макеты рисует Claude в Claude Design (чат проекта на claude.ai) и сам кладёт сюда картинки и исходник. Claude Code строит экраны по ним и сверяет результат скриншотами через Playwright.

Картинки сделаны в двойной плотности (Retina) и показывают страницу целиком по высоте.

### Как читать исходник

`Desk.dc.html` — формат Claude Design: разметка с подстановками `{{...}}`, `<sc-if>` (условие) и `<sc-for>` (повтор), а внизу класс `Component` с функцией `renderVals()`, где лежат данные и вычисления. Переносить нужно не формат, а содержание:

- цвета, размеры, отступы и шрифты из inline-стилей → CSS-переменные в `styles.css`;
- `bucketFor()`, `defaults()` и `metrics()` — логика перестройки окна: точки 1440 / 1200 / 1024 / 860, ширины панелей, правило «контент не уже 560 px», когда правая панель становится выезжающей;
- `startDrag()` / `onMove()` / `keyResize()` — перетаскивание границ панелей мышью и стрелками, двойной щелчок сбрасывает ширину;
- данные (решения, инсайты, игроки, таблица) — вымышленные заглушки; в игре они придут из ядра.

Иконки в макете нарисованы вручную похожими на Lucide; в коде берём настоящие иконки Lucide.

## Досье игрока

| Файл                             | Что это                                                                     |
| -------------------------------- | --------------------------------------------------------------------------- |
| `dossier-1440.png`               | Досье в окне 1440 px: оценки слева, знание, следующий шаг и данные справа   |
| `dossier-1024.png`               | Окно 1024 px: правая колонка уходит под основную                            |
| `source/dossier/Dossier.dc.html` | Исходник: диапазоны оценок, знание по блокам, выбор матча и скаута, правила |

Логика экрана — `docs/concept.md`, раздел 9 «Знание об игроке и реалистичный скаутинг». Перевод 1–20 в слова — функция `word()`; диапазон рисуется полосой от нижней до верхней оценки; «не видели» — пунктир. Числа 1–20 показываются только при включённой настройке (в макете — переключатель `showNumbers`). Все цифры и имена — вымышленные заглушки.

## Состав

| Файл                         | Что это                                                                      |
| ---------------------------- | ---------------------------------------------------------------------------- |
| `squad-1440.png`             | Состав в окне 1440 px: таблица по линиям и карточка выбранного игрока справа |
| `squad-1200.png`             | Окно 1200 px: карточка скрыта, в таблице появляется возраст                  |
| `squad-1024.png`             | Окно 1024 px: меню иконками                                                  |
| `squad-800.png`              | Окно 800 px: меню скрыто, часть колонок спрятана                             |
| `source/squad/Squad.dc.html` | Исходник: группы, сохранённые виды, правило скрытия колонок, карточка игрока |

- Колонки прячутся по приоритету, когда не помещаются (порядок добавления: нагрузка, роль, возраст, контракт, зарплата) — см. расчёт `avail` и `used` в исходнике. Обязательные: №, игрок, статус, готовность, уровень.
- Сохранённые виды («Основа», «Медицина и нагрузка», «Контракты до 2027», «Молодёжь до 21») — это фильтры; «+» сохраняет текущие фильтры и колонки как свой вид (ADR-014).
- Свои игроки известны почти точно: уровень одним словом досье, без диапазонов.

## Правила

- Имена файлов: `<экран>-<ширина>.png`, состояния — суффиксом (`home-800-menu.png`); исходники — `source/<экран>/`.
- Макет — эталон компоновки, плотности и поведения при сужении окна. Если цвета или отступы расходятся с макетом, правим CSS-переменные, а не отдельные экраны.
- Все данные на макетах вымышленные.
