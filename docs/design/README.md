# Макеты экранов

Эталонные макеты делаются в Claude Design (чат проекта на claude.ai) и кладутся сюда картинками. Claude Code строит экраны по ним и сверяет результат скриншотами через Playwright.

## Что положить сюда сейчас

Из макета «Главная — рабочий стол тренера» (главная v2) выгрузите четыре картинки и сохраните под такими именами:

| Файл            | Что это                                                                                            |
| --------------- | -------------------------------------------------------------------------------------------------- |
| `home-1440.png` | Главная в окне 1440 px и шире: меню, контент, правая панель                                        |
| `home-1200.png` | Окно 1200 px: правая панель уже                                                                    |
| `home-1024.png` | Окно 1024 px: меню иконками, правая панель скрыта                                                  |
| `home-800.png`  | Окно 800 px: меню скрыто и выезжает по кнопке, виджеты в одну колонку, вкладки в выпадающем списке |

В интерактивном макете (кнопка Play) можно потянуть границу меню и правой панели: так выглядит изменение ширины панелей мышью. Внизу экрана показаны ширина окна, ширина контента и режим.

## Правила

- Имена файлов: `<экран>-<ширина>.png`, например `dossier-1440.png`.
- Макет — эталон компоновки, плотности и поведения при сужении окна. Цвета, отступы и шрифты закрепляются в CSS-переменных; если они расходятся с макетом, правим переменные, а не отдельные экраны.
- Все данные на макетах вымышленные.
