# T001 — Отчёт

## Шаг 1. Каркас репозитория — выполнен

Дата: 2026-10-25. Проверялось в облачной сессии Claude Code (Linux x64, Node 22.22).

### Что сделано

- npm workspaces: `apps/desktop` (Electron + electron-vite + React), `packages/sim` (ядро), `packages/shared` (общие типы и контракт моста).
- TypeScript strict во всех пакетах (плюс `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`).
- ESLint (с правилами изоляции и детерминизма ядра), Prettier, Vitest, Playwright.
- Команды: `dev`, `dev:web`, `typecheck`, `lint`, `format`, `test`, `test:e2e`, `bench`, `build`.
- Окно Electron: `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`. Ссылки открываются во внешнем браузере. Content-Security-Policy в `index.html`.
- Типизированный мост `window.api` (`AppApi` в `packages/shared`): пока один метод `getAppInfo` через IPC. Мок моста для браузера — `apps/desktop/src/renderer/src/bridge.ts`.
- Экран-заглушка: название, среда (Electron или браузер), платформа, версия ядра.

### Как проверить самому (на Mac)

Нужны Git и Node.js 22 LTS.

```
git clone https://github.com/theosmanovwork-lang/football1.git
cd football1
npm install
npm run dev
```

Должно открыться окно «Футбольный менеджер» со строкой «Среда: Приложение Electron». Закрыть — Cmd+Q.

```
npm run dev:web
```

Откройте в браузере http://localhost:5173 — та же заглушка, но «Среда: Браузер (мок моста)». Остановить — Ctrl+C в терминале.

### Проблемы и решения

- **macOS 12 у пользователя.** Electron 44+ требует macOS 13, поэтому закреплён Electron 43 (ADR-004).
- **TypeScript 7** не поддерживается линтером — взят 6.0 (ADR-005).
- **Vitest:** `bench` в Vitest 5 экспериментальный, Vitest 4 не устанавливается — замеры сделаны через обычные тесты с таймером (ADR-005).
- Сборка `.dmg` под macOS проверяется только на Mac (`npm run build`); в облаке проверена сборка под Linux.
